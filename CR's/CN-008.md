# CN-008 - Render HTML Reports Visually Inside Dashboard

## Summary

Fixed dashboard file serving so generated `.html` reports render visually inside the dashboard iframe instead of being served as plain text.

## Files Changed

- `src/dashboard_server.py`

## Behavior

- `/file?path=...html` now returns `Content-Type: text/html`.
- `/file?path=...json` returns `application/json`.
- `/file?path=...csv` returns `text/csv`.
- The dashboard iframe can now visually render prediction reports within the same dashboard page.

## Validation

- `python -m compileall src/dashboard_server.py` passed.
- Restarted dashboard server on `http://127.0.0.1:8765`.
- Verified existing report endpoint returns:
  - HTTP `200`
  - `Content-Type: text/html; charset=utf-8`
- Called `POST /api/predict`.
- API returned `returncode=0`.
- Generated report:
  - `output/prediction_log_report_ETHUSD_MINUTE_5_20260429T210339Z.html`
- Verified generated report endpoint returns:
  - HTTP `200`
  - `Content-Type: text/html; charset=utf-8`
- Verified generated report contains:
  - `Prediction Log Report`
  - `Forecast Close Path`
