# CN-006 - Prediction Log HTML Report

## Summary

Added a forecast-only HTML report for current/future prediction outputs where actual candles are not available yet.

## Files Changed

- `src/prediction_log_report.py`
- `src/main_generate_prediction_log_report.py`

## Behavior

- Loads forecast CSV, metadata JSON, and validation JSON.
- Displays forecast window in `Asia/Amman`.
- Visualizes forecast close path and forecast volume path.
- Includes a forecast candle table.
- Does not require actual candles.

## Safety

- Report-only.
- No trading endpoints.
