# CN-012 - Dashboard-Owned Continuous Workers

## Summary

Updated `start_dashboard.ps1` so launching the dashboard also starts the continuous prediction scheduler and validation worker.

## Changed Files

- `start_dashboard.ps1`

## Behavior

- Starts `src/main_prediction_scheduler.py` in continuous mode.
- Starts `src/main_validation_worker.py` in continuous mode.
- Starts the dashboard at `http://127.0.0.1:8765`.
- Pressing `Ctrl+C` in the dashboard PowerShell session stops the dashboard and both background workers.
- Uses environment variables for symbol, market, resolution, interval, Capital.com environment, and PostgreSQL DSN.

## Safety

This remains data-only signal generation and validation. No order execution or trading endpoint was added.
