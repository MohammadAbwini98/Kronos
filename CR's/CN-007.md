# CN-007 - Render Prediction Report Inside Dashboard

## Summary

Updated the dashboard so clicking `Run Prediction` generates a prediction log report and embeds it in the same dashboard page.

## Files Changed

- `src/dashboard_server.py`

## Behavior

- `/api/predict` runs the latest forecast workflow.
- On success, it generates `output/prediction_log_report_{epic}_{resolution}_{timestamp}.html`.
- The API response includes `report_url`.
- The dashboard displays the report in an iframe and provides an open-report link.

## Safety

- Dashboard remains data/report-only.
- No trading endpoints.

## Validation

- `python -m compileall src/dashboard_server.py` passed.
- Restarted local dashboard server on `http://127.0.0.1:8765`.
- Called `POST /api/predict`.
- API returned `returncode=0`.
- API returned report URL:
  - `/file?path=output/prediction_log_report_ETHUSD_MINUTE_5_20260429T202305Z.html`
- Verified generated report exists:
  - `output/prediction_log_report_ETHUSD_MINUTE_5_20260429T202305Z.html`
- Verified dashboard serves the report URL with HTTP `200`.
- Verified report contains:
  - `Prediction Log Report`
  - `Times shown in Asia/Amman`
