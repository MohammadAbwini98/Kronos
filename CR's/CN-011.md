## Behavior

- PostgreSQL schema stores instruments, OHLCV candles, raw events, prediction runs, forecast candles, signals, validation outcomes, and service heartbeats.
- Historical and latest fetches upsert candles into PostgreSQL.
- WebSocket OHLC events upsert live candles into PostgreSQL.
- Kronos prediction runs save forecast candles and one signal decision per run.
- Validation updates each forecast candle outcome as `WIN`, `LOSS`, or `PENDING`.
- Scheduler can run a current/future Kronos prediction every 5 minutes.
- Validation worker checks completed forecast windows and validates outcomes.
- Dashboard status includes PostgreSQL signal/outcome/candle snapshots.

## Safety

This remains signal generation only. No order, position, working order, BUY/SELL execution, or live trading endpoint was implemented.
