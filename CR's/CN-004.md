# CN-004 - Add Latest Current/Future Forecast Wrapper

## Summary

Added a wrapper script that fetches the latest Capital.com candles before running Kronos, so live/current forecasts start from the newest completed input candle instead of an old held-out validation window.

## Files Changed

- `src/main_forecast_latest.py`
- `README.md`

## Behavior

- Authenticates to Capital.com.
- Resolves the requested market/epic.
- Fetches latest historical candles.
- Saves the normal Kronos input CSV.
- Runs local Kronos using `src/main_run_kronos_predict.py`.
- Prints the forecast window in `Asia/Amman`.
- Retries with `--repair-ohlc` if raw Kronos output violates the OHLC envelope and the caller did not already pass repair mode.

## Safety

- Data-only workflow.
- No order, position, working-order, or execution endpoints.
