# CN-005 - Add 3-Month Historical Fetch and Prediction Dashboard

## Summary

Added a chunked historical range fetcher and a local dashboard with a `Run Prediction` button.

## Files Changed

- `src/main_fetch_historical_range.py`
- `src/dashboard_server.py`
- `start_dashboard.ps1`
- `README.md`

## Behavior

- `main_fetch_historical_range.py` fetches a configurable multi-month historical range in chunks and saves a Kronos-compatible CSV.
- `dashboard_server.py` serves a local browser dashboard at `http://127.0.0.1:8765`.
- The dashboard opens automatically by default.
- The dashboard `Run Prediction` button calls the safe latest-forecast workflow.

## Safety

- Dashboard only calls data and forecast scripts.
- No trading endpoints.
- No execution logic.
